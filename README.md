# Multi-Site Enterprise Network Design with VLAN Segmentation

A Cisco Packet Tracer project modeling a two-site enterprise network for Northstar Services, connecting Cairo and Alexandria.

## Topology

- Serial WAN link between the Cairo and Alexandria routers
- Departmental VLANs: VLAN 10, VLAN 20, VLAN 30, and VLAN 40
- Management VLAN: VLAN 99
- Access switches and end devices distributed across both sites

## Technologies

Cisco Packet Tracer, Cisco routers and switches, VLAN segmentation, WAN serial connectivity, and IP subnetting.

## Project file

Open `Multi-Site Enterprise Network Design with VLAN Segmentation.pkt` with Cisco Packet Tracer.
